# Address Book Application in C

## Overview
A menu-driven Address Book application developed using C programming
as part of my Embedded Systems training at Emertxe.

## Features
- Create contacts
- Search contacts
- Edit contact details
- Delete contacts
- Display contacts in alphabetical order
- Validate phone numbers and email addresses
- Save and load contacts using file handling

## Concepts Used
- C programming
- Structures
- Pointers
- String handling
- File handling
- Input validation
- Sorting algorithms

## How to Compile
gcc main.c contact.c validation.c file.c -o address_book

## How to Run
./address_book
